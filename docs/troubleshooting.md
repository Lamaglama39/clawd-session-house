# 困ったとき

ログの場所は、手動で入れた場合は`run/server-8765.log`、プラグインで入れた場合は`~/.claude/plugins/data/clawd-session-house-lamaglama39/run/server-8765.log`です。

## タイルが表示されない

1. `curl http://127.0.0.1:8765/healthz`で、サーバーが応答するか確認します。`ok`と返れば正常です。
2. フックが登録されているか、Claude Codeの`/hooks`で確認します。
3. テスト用のイベントを送り、タイルが出るか確認します。

   ```bash
   curl -s -H 'Content-Type: application/json' http://127.0.0.1:8765/hook \
     -d '{"session_id":"test","cwd":"/tmp/test","hook_event_name":"UserPromptSubmit"}'
   ```

4. ログに`test UserPromptSubmit -> BUSY`のような行が出ているか確認します。

テスト用のタイルが出るのにセッションのタイルが出ない場合は、フックからイベントが届いていません。テスト用のタイルは、サーバーを起動し直すと消えます。

## サブエージェントやタスクが表示されない

手動で入れた場合は、`SubagentStart`などのフックが登録されていない可能性があります。`python3 plugin/scripts/install-hooks.py`を実行し直してください。

## 振り返り画面に「履歴を読み込めません」と出る

サーバーが`--no-history`で起動しているか、記録を保存できていません。
ログに`history: disabled`と出ている場合は、保存先のフォルダに書き込めるか確認してください。
そのあと、サーバーを起動し直します。

- プラグインで入れた場合: `/clawd-session-house:restart`
- 手動で入れた場合: `./plugin/scripts/stop-server.sh && ./plugin/scripts/start-server.sh`

## 承認を拒否したのに「承認待ち」のまま / Escで中断したのに「処理中」のまま

承認ダイアログで拒否したときと、Escで中断したときは、Claude Codeがフックを送りません。
次のプロンプトを送ると、正しい状態に戻ります。Claudeの応答のあと約60秒何も入力しないと届く`idle_prompt`の通知で、待機中に戻ることもあります。

## セッションを閉じたのにタイルが残る

Claude Codeが異常終了するなどして`SessionEnd`が届かなかった場合、そのタイルは動いているセッションのまま残ります。
タイルにマウスを乗せると右上に「×」が出るので、押して「消す」に変わったら、もう一度押すと消えます。
何もしなくても、イベントが12時間届かなければ自動で消えます。この時間は`--expire-hours`で変えられます。

## 並列でツールを実行したとき、承認待ちが一瞬で消える

複数のツールを並列で実行している最中に承認を求められると、別のツールが終わったイベントで、一時的に「処理中」に戻ることがあります。
Claude Codeの承認ダイアログは出たままなので、Claude Codeの画面を確認してください。

## 通知が出ない

- ヘッダーのボタンが「通知 オン」になっているか確認します。「通知 ブロック中」の場合は、ブラウザのサイト設定で`127.0.0.1`の通知を許可してください。
- ダッシュボードを見ている間は通知しません。別のアプリに切り替えてから確かめてください。
- ダッシュボードのタブを開いたままにしてください。閉じている間や、振り返りを開いている間は通知しません。
- macOSの「システム設定」→「通知」で、Google Chromeなど使っているブラウザの「通知を許可」がオンになっているか確認してください。
- おやすみモードなどの集中モードがオンだと、通知センターには届いても画面には出ません。
- 承認待ちの通知は、承認を求められたときだけ出ます。auto modeなど承認なしで進む設定では、その分だけ少なくなります。処理完了の通知は、1分以上続いた処理だけです。

## 記録が二重に数えられる

プラグインと手動の両方でフックを登録していると、イベントが2回届きます。
プラグインを使っていて、`~/.claude/settings.json`に`# clawd-session-house`の付いたフックが残っているときは、リポジトリの直下で`python3 plugin/scripts/install-hooks.py --uninstall`を実行して外してください。

## ポートが使用中で起動できない

ログに`cannot listen on ...`と出ている場合は、[ポートを変える](configuration.md#ポートを変える)の手順で別のポートを指定してください。
